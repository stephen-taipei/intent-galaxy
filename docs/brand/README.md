# Intent Galaxy 品牌素材

| 檔案 | 用途 |
| --- | --- |
| `intent-galaxy-logo.svg` | 圖形＋文字，淺色背景 |
| `intent-galaxy-logo-dark.svg` | 圖形＋白色文字，深色背景 |
| `intent-galaxy-mark.svg` | 只有圖形（擴充功能圖示、favicon、頭像） |
| `intent-galaxy-logo.png` | 原始設計稿點陣版（1254×1254，圖形在上、文字在下，白底），商店宣傳圖等需要 PNG 時使用 |

三條光帶收束到菱形：四面發散的想法，收斂成一個鎖定的意圖。

## 顏色

| 名稱 | 色碼 |
| --- | --- |
| 藍（外側光帶） | `#0071FE` |
| 紫（中央光帶、菱形） | `#7A3BF1` |
| 深藍（文字） | `#06173E` |

## 字型

文字是 [Figtree](https://fonts.google.com/specimen/Figtree)（SIL Open Font License 1.1）wght 760 轉成的外框，字距 −27/1000 em，SVG 不依賴任何字型檔。

## 幾何

圖形以菱形中心線上下對稱；三條光帶與菱形的間隙一致（28），菱形為正方形旋轉 45°、圓角 20（以 viewBox 單位計）。

擴充功能的 PNG 圖示（`apps/extension/icons/`）由 `intent-galaxy-mark.svg` 輸出。
