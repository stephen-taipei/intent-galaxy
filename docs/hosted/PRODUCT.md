# 官網產品定位與重複使用設計

狀態：可審查的開發版本；尚未部署、開啟真實模型或正式收費。查核日期：2026-10-29。

## 定位

Stephen.Taipei 的教學入口負責幫使用者理解方法、跟做及查證。AI 工作室負責把方法用在當下的一件工作，留下可修改、可核對、可重用的成果。第一版聚焦個人知識工作者：回覆訊息、週報與下一步、方案比較與規劃。既有作品與經歷仍保留。

使用者不必先學會操作星系。先用三張方案卡選擇方向；需要理解取捨時，再展開 Intent Galaxy v2 星系。需求摘要經使用者確認後，才呼叫生成 API。AI 不會替使用者寄信、執行程式、購買或作出對外承諾。

## 回訪方式

循環是「選任務 → 補上這次資料 → 看取捨 → 確認需求 → 修改成果 → 明確儲存 → 下次只帶入勾選欄位」。範本保留穩定的語氣、結構與要求；日期、進度、選項及其他會變動的事實由使用者重新確認。重新生成仍重新分析，不沿用舊評估當作通過證據。

九宮格另有循環：「一個目標 → 八個主題 → 六十四個行動 → 勾選實際完成項目與筆記 → 定期回顧 → 調整下一步」。完整手動編輯、本機保存、JSON／Markdown 匯出與列印都免費。AI 展開只是提案，必須明確套用，不覆寫原有目標、行動文字、完成狀態或筆記。

這是回訪假設，尚無留存或付費轉換實證。第一輪以實際完成作品、再次使用範本、再次回顧目標及成本觀察是否有價值。事件只接受固定名稱與模板識別字，不記錄輸入正文；不以單次點擊或單日流量證明產品成功。

## Decisions API 的高價值位置

1. 分析後檢查背景是否足夠，提出最多三個待補問題；可建議任務類型，但不改掉使用者的選擇。
2. 生成後檢查事實是否受輸入支持、是否新增未授權承諾、是否回應指定成果及要求。
3. 與固定規則檢查並列。字數、必含／禁用文字由程式判斷；規則失敗不能被模型評分抵銷。

判定是「通過／不通過／無法判定」。機率不呈現為真實正確率；資訊不足、拒答、逾時及格式錯誤不算通過。成果或需求變動會使原評估失效。Claude 生成內容只有在使用者另行同意時才交給 OpenAI 檢查。

120 個案例目前是待人工審核的標記草案，尚未跑真模型品質測試。只有固定資料集、保留組、模型與規準版本相符，並經人工標記審查及授權實跑後，才可判定誤放行率與覆蓋率。`MODEL_QUALITY_APPROVED` 預設關閉。

## 方法來源與使用界線

- [OpenAI Decisions API](https://developers.openai.com/api/docs/guides/decisions)：提供結構化 predicate／choice 判斷，作為輔助檢查的技術依據。
- [OpenAI API pricing](https://developers.openai.com/api/docs/pricing)、[Claude Models overview](https://platform.claude.com/docs/en/models/overview)：固定模型及成本保留估計的來源。實際成本仍須與供應商帳單核對；不完整的快取／服務層級費用會保留預算，不用部分 token 費用釋放額度。
- [Harvard Gazette：Crush your goals the Ohtani way](https://news.harvard.edu/gazette/story/2026/02/crush-your-goals-the-ohtani-way/)：九宮格／Harada 方法背景。產品採一般目標拆解方法，未使用球員肖像、商標或聲稱代言，也不把名人案例當作成果保證。
- Paddle 使用 sandbox；商家審查、實際含稅交易、退款及營運政策驗證完成前，不開啟正式收費。完整環境與驗證流程見 `DEPLOYMENT.md`。
